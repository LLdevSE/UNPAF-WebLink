# Countdown to UNPAF

This is a simple web page that displays a countdown and then redirects to the UNPAF website. It features a clean, dark-themed interface with animations and a fireworks effect upon completion of the countdown.

## Features

- 5-second countdown timer.
- "Welcome to UNPAF" message.
- Fireworks effect.
- Redirect to the UNPAF website.
- Responsive design for mobile and desktop.

## How to Run

1. Clone this repository.
2. Open the `index.html` file in your web browser.
